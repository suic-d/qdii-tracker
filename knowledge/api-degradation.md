# API 降级决策树

> 每个数据源的 fallback 链路。设格式：主源 → 备用源 → 最终兜底。

## 净值数据（lsjz / nav）

| 优先级 | 数据源 | 接口 | 降级条件 |
|--------|--------|------|----------|
| 1 (主) | 天天基金 lsjz | `FundOpenInfo.getFundHistory` | — |
| 2 (备) | pingzhongdata pzd | `_fetch_pzd_api` | lsjz 超时或返回空 |
| 兜底 | 保留旧值 | nav_date 保持最近成功日期 | 双源均失败，**绝不回退** |

> 关键约束：nav_date 永不回退。即使 pzd 也失败，保留上次成功获取的净值，不推算。

## 基金基础信息（scale / manager / fee）

| 优先级 | 数据源 | 适用基金类型 | 降级条件 |
|--------|--------|-------------|----------|
| 1 (主) | 天天基金 | 大部分场外 QDII | — |
| 2 (备) | 雪球 (xueqiu_source) | 少部分天天不覆盖的基金 | 天天返回空 / 字段缺失 |
| 兜底 | 标记为 null / 保留旧值 | 全部 | 双源均失败 |

## 申购状态（buy_status）

| 优先级 | 数据源 | 说明 |
|--------|--------|------|
| 1 (主) | 天天基金实时接口 | 每次 fill 后刷新 |
| 兜底 | buy_status_history 最后一条 | 前值保留 |

## 涨跌幅（chg_day / chg_ytd）

| 优先级 | 数据源 | 说明 |
|--------|--------|------|
| 1 (主) | AKShare fund_rank | enrich 阶段拉取 |
| 2 (备) | LOF 同系列兄弟份额 | chg_ytd 兜底（A/C 差异 <1%） |
| 兜底 | null | 不占位假值 |

## 基金搜索/分类

| 优先级 | 数据源 | 说明 |
|--------|--------|------|
| 1 (主) | AKShare 全量搜索 | scan 阶段按板块分拣 |
| 兜底 | force_include 白名单 | 手动指定，跳过自动搜索 |

## 实时盘中数据

| 数据 | 数据源 | 刷新频率 |
|------|--------|----------|
| ETF 溢价率 | AKShare (sina/qq) | 盘中 60s |
| 市场指数 | AKShare | 盘中 60s / 盘后 5min |
| 场外净值 | lsjz → pzd | idle-scheduler 调度 |

## 故障处理原则

1. **静默降级**：单只基金失败不阻塞整批
2. **nav_date 不回退**：无论什么原因
3. **标记而非删除**：失败数据标记缺省而非删除已有值
4. **强制纳入兜底**：force_include 的白名单基金跳过自动搜索
